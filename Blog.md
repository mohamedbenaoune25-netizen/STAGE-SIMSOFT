- **Surface Variant**: `#e5e2e1`

## Typography
- **Headline Display**: Hanken Grotesk, 64px, 800 weight, -0.04em letter spacing
- **Headline Large**: Hanken Grotesk, 40px, 700 weight, -0.02em letter spacing
- **Body Large**: Inter, 18px, 400 weight
- **Body Medium**: Inter, 16px, 400 weight
- **Label Caps**: JetBrains Mono, 12px, 500 weight, 0.1em letter spacing

## Layout
- **Margin Desktop**: 64px
- **Grid Unit**: 40px
- **Gutter**: 24px

## Components
- **Buttons**: Square corners (0px radius), tracking-widest, uppercase.
- **Section Transitions**: Diagonal splits (oblique lines).
- **Cards**: Bordered with `border-grid`, grayscale images with hover effects.
